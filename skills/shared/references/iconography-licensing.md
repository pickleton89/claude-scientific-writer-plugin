# Iconography Licensing — Scientific Illustration Libraries

> Licensing terms, attribution templates, and pre-submission verification for the major scientific illustration libraries used in publications, posters, slides, and graphical abstracts.
> Version: 1.0.0
> Used by: paperbanana, scientific-schematics, research-posters, plotting-libraries, scientific-slides
>
> **Re-verify at submission.** Library terms change. Pre-2024 blog posts about biomedical illustration licensing are often wrong because of material changes in 2023–2026.

## BioRender

**Tiered model** (verify at biorender.com/pricing — terms revised 2026-01-16):

| Plan | Watermark | Publication rights | Notes |
|---|---|---|---|
| Basic (free) | Yes | **No** | Internal use only; cannot publish in journals or posters |
| Academic Individual | No | Yes — first author / co-first / co-senior / last-author requirement | Each published author needs an active seat **at the time of submission** |
| Academic Lab | No | Yes — covers all lab members | Lifts the per-author seat requirement |
| Institutional | No | Yes — covers institution-wide users | Lifts seat requirement; common at large universities |
| Industry / Commercial | No | Yes | Required for commercial use |

**Key rules:**
- Open-access export is licensed **CC-BY-4.0**; paywalled-journal exports are **non-CC** and remain proprietary.
- Authorship requirement: BioRender's terms (rev. 2026-01-16) require that the author whose seat is used for publication be the **first author, co-first author, co-senior author, or last author** of the publication, unless the lab/institutional plan applies.
- Persistence: BioRender illustrations published while you held an active subscription remain licensed for that publication after subscription cancellation. New publications after cancellation require a new seat.
- Accepting publishers (verified): Cell Press, Nature Publishing Group, Elsevier, eLife, PNAS, APS, Science (with attribution).

**Attribution template:**

```
Created in BioRender. <Author Last Name>, <First Initial>. (<Year>) https://BioRender.com/<publication-link>
```

The publication-link is generated by BioRender's "Publish for Journal" export workflow and produces a verifiable URL.

**Verification at submission:**
- [ ] Active BioRender subscription confirmed for at least one of the first/co-first/co-senior/last authors (or lab/institutional plan active).
- [ ] License PDF downloaded from BioRender and saved to manuscript supplement folder.
- [ ] Attribution string added to figure caption with publication link.

## NIH BIOART

NIH-funded illustration library launched October 2024. US Government works are in the public domain in the US; international users typically apply CC0 or attribution-recommended.

- URL: https://bioart.niaid.nih.gov
- Formats: EPS, AI, PNG, SVG.
- Coverage: Pathogens, cells, organs, lab techniques (initial focus on infectious-disease and immunology contexts).
- Cost: Free.
- Attribution: Recommended ("Image courtesy of NIH BIOART") but not legally required for US users.

**Attribution template:**

```
Image source: NIH BIOART (https://bioart.niaid.nih.gov). U.S. Government work, public domain.
```

## SciDraw

Open repository of CC-BY-4.0 scientific illustrations, primarily neuroscience and behaviour.

- URL: https://scidraw.io
- Founders: Federico Claudi, Alex Harston.
- License: CC-BY-4.0 (commercial permitted with attribution).
- Format: PNG and editable source where provided.
- Citation: Each illustration has a DOI; cite the DOI in the figure caption.

**Attribution template:**

```
<Illustration title>, by <Creator name>, SciDraw (doi:<scidraw DOI>). CC-BY-4.0.
```

## Smart Servier Medical Art

Owned by Servier (pharmaceutical company); relaunched 2023 with a permissive open-content policy.

- URL: https://smart.servier.com
- License: **CC-BY-4.0** (changed from CC-BY-3.0 at 2023 relaunch).
- Format: PNG, PowerPoint slides bundled by anatomical region.
- Constraint: Servier branding (logo, name) must **not** appear in derivative works; the illustrations themselves are unrestricted.

**Attribution template:**

```
Illustrations adapted from Smart Servier Medical Art (https://smart.servier.com), licensed CC-BY-4.0.
```

## Noun Project

Large icon library; mixed licensing per icon.

- URL: https://thenounproject.com
- Free tier: CC-BY-3.0 — must credit creator and Noun Project name.
- CC0 subset: Some icons are CC0 (public domain) — verify per icon.
- Pro / paid: Custom commercial license; no attribution required.

**Attribution template (free tier):**

```
"<Icon name>" icon by <Creator>, the Noun Project (CC-BY-3.0).
```

## Pre-submission verification checklist

- [ ] Each composited icon's source library identified.
- [ ] Free-tier libraries: attribution string added to caption.
- [ ] BioRender: active seat confirmed; license PDF saved; publication-link URL added to caption.
- [ ] CC-BY-NC-SA-4.0 (Somersault) icons not used in commercially-funded work.
- [ ] No Servier branding present in any derivative.
- [ ] License terms re-verified at the library's current URL (terms change ~annually).

# Results Scoring Calibration

> Reference examples for consistent results presentation scoring (1-5 scale).
> Weight: 10% of overall score.

---

## Score 5 Example (Excellent)

**Excerpt:**
> "Treatment with compound X significantly reduced tumor volume compared to vehicle control (mean ± SEM: 145 ± 23 mm³ vs 412 ± 45 mm³; Cohen's d = 1.8, 95% CI [1.2, 2.4]; one-way ANOVA F(2,27) = 24.3, p < 0.001; Tukey post-hoc p < 0.001; n=10/group). Figure 2A shows individual data points overlaid on box plots, with outliers identified using Tukey's fences. The effect was dose-dependent (Figure 2B; linear regression R² = 0.89, p < 0.001)."

**Why Score 5:**
- Effect sizes with confidence intervals
- Full statistical reporting (test, df, F, p)
- Sample sizes explicit
- Individual data shown
- Variability clearly defined (SEM)
- Dose-response relationship quantified

**Key Indicators:**
- ✓ Effect size with CI
- ✓ Complete statistical details
- ✓ Data points visible
- ✓ Error type defined
- ✓ Relationship quantified

---

## Score 4 Example (Good)

**Excerpt:**
> "Compound X reduced tumor volume significantly (145 ± 23 mm³ vs 412 ± 45 mm³, p < 0.001, n=10/group). Treatment showed a dose-dependent effect (R² = 0.89, p < 0.001). See Figure 2 for representative images and quantification."

**Why Score 4:**
- Quantitative comparison
- P-values provided
- Sample sizes stated
- Missing effect size/CI
- Figure reference clear
- Minor details omitted

**Key Indicators:**
- ✓ Quantitative data
- ✓ P-values present
- ✓ Sample sizes
- ○ No effect size
- ○ Error type not always explicit

---

## Score 3 Example (Adequate)

**Excerpt:**
> "Treatment significantly reduced tumor size (p < 0.05). The effect was dose-dependent. Results are shown in Figure 2."

**Why Score 3:**
- Claims statistical significance
- Dose-dependence mentioned
- No quantitative data in text
- Relies entirely on figures
- P-value threshold only
- Reader must extract numbers

**Key Indicators:**
- ○ Qualitative description
- ○ P-value threshold only
- ○ No effect magnitudes
- ○ Figure-dependent
- ○ Interpretation possible

---

## Score 2 Example (Needs Work)

**Excerpt:**
> "Treatment reduced tumor size. The results were significant and dose-dependent (Figure 2)."

**Why Score 2:**
- No quantitative data
- "Significant" without stats
- No sample sizes
- Cannot evaluate claims
- Vague language

**Key Indicators:**
- ✗ No numbers
- ✗ No statistics
- ✗ No sample sizes
- ✗ Vague claims

---

## Score 1 Example (Poor)

**Excerpt:**
> "The treatment worked well and showed good results."

**Why Score 1:**
- Completely non-quantitative
- No data presented
- Subjective language ("worked well", "good")
- Cannot evaluate validity
- Requires complete rewrite

**Key Indicators:**
- ✗ No data
- ✗ Subjective claims
- ✗ Not scientific reporting

---

## Figure Evaluation Rubric

When scoring Results, evaluate figures using these criteria:

| Criterion | Score 5 | Score 3 | Score 1 |
|-----------|---------|---------|---------|
| Data points | Individual shown | Mean only | Not visible |
| Error bars | Defined (SD/SEM/CI) | Present, undefined | Missing |
| Statistics | Full (test, n, p, effect) | p-value only | None |
| Labels | Complete, readable | Partial | Missing/unclear |
| Legend | Self-explanatory | Adequate | Insufficient |

---

## Common Scoring Pitfalls

1. **Penalizing brevity:** Short results that point to well-labeled figures can score 4-5.

2. **Ignoring figure quality:** Text score should account for figure completeness.

3. **Over-weighting p-values:** p < 0.001 means nothing without effect sizes.

4. **Missing negative results:** Score should be reduced if expected negative results are omitted.

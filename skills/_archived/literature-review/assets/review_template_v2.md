### Appendix H: Figure Design Guidelines

#### Chart Selection Guide

| Purpose | Recommended Chart | Avoid |
|---------|-------------------|-------|
| Compare categories | Horizontal bar chart | Pie charts for >5 categories |
| Show composition | 100% stacked bar | 3D charts |
| Display trends over time | Line chart | Bar charts for continuous time |
| Explore patterns | Heatmap | Heatmaps for precise comparison |
| Show hierarchy | Treemap | Overcrowded treemaps |
| Meta-analysis effects | Forest plot | Tables alone |
| Publication bias | Funnel plot | — |

#### Design Principles

1. **Hierarchy**: Title (largest) → Axis labels → Data labels → Notes (smallest)
2. **White space**: Minimum 10% margins; space between grouped elements
3. **Alignment**: All elements aligned to a consistent grid
4. **Proximity**: Related items grouped; unrelated items separated

#### Color Guidelines

- **Sequential data** (low→high): Single hue, varying saturation
- **Diverging data** (below/above midpoint): Two-hue scheme
- **Categorical data**: Distinct hues; maximum 7 categories
- **Accessibility**: Test with colorblind simulators; use patterns as backup

#### Figure Specifications

- **Resolution**: Minimum 300 DPI for print; 150 DPI for screen
- **Format**: Vector (SVG, PDF) preferred; PNG for raster
- **Font**: Sans-serif (Arial, Helvetica); minimum 8pt
- **Line weight**: Minimum 0.5pt; 1pt recommended

#### Forest Plot Best Practices

- Order studies by effect size or chronologically (be consistent)
- Include study weights visually (box size)
- Show summary diamond for pooled estimate
- Include heterogeneity statistics (I², p-value)
- Clearly mark the line of no effect

#### Visual Abstract Template

A visual abstract should include:
1. **Header**: Title and authors
2. **The Question**: 1-2 sentences
3. **Methods Summary**: Icon-based (databases → screening → included)
4. **Key Finding**: Central visual element (chart or infographic)
5. **Conclusion**: 1 sentence
6. **Registration**: PROSPERO ID

## Template Usage Guide

**DELETE THIS SECTION BEFORE FINALIZING YOUR REVIEW**

### Adapting for Review Type

| Review Type | Required Sections | Optional/Omit |
|-------------|-------------------|---------------|
| **Systematic Review** | All core sections | Meta-analysis sections if not pooling |
| **Meta-Analysis** | All sections including 3.3 | — |
| **Narrative Review** | Core sections; compress Methods | Detailed appendices |
| **Scoping Review** | Follow PRISMA-ScR | Quality assessment may be omitted |
| **Umbrella Review** | All sections; add AMSTAR 2 | — |

### Writing Principles

1. **One Thing**: Identify your single key message before writing; place it first AND last
2. **Answer First**: Lead every section with conclusions, then provide evidence
3. **Declarative Headers**: Convert all headers to statements that tell the story
4. **Thematic Synthesis**: Organize by finding, not by study
5. **Strategic Omission**: Include only what changes understanding or decisions
6. **Audience Awareness**: Design for multiple readers using Reading Pathways

### Headline Transformation Examples

| Generic Header | Declarative Header |
|----------------|--------------------|
| "Study Selection" | "47 Studies Met Rigorous Inclusion Criteria" |
| "Main Findings" | "Early Intervention Consistently Outperforms Delayed Treatment" |
| "Strengths and Limitations" | "High Confidence Despite Moderate Heterogeneity" |
| "Knowledge Gaps" | "Three Critical Questions Remain Unanswered" |

### Common Pitfalls

**Avoid**:
- ❌ Listing studies one-by-one without synthesis
- ❌ Passive, generic section headers
- ❌ Burying key findings in results section
- ❌ Cherry-picking favorable results
- ❌ Overstating conclusions beyond evidence certainty
- ❌ Ignoring or minimizing limitations
- ❌ Skipping publication bias assessment
- ❌ Dense methodology in main text (move to appendices)

**Do**:
- ✓ State your key finding on page 1
- ✓ Synthesize thematically across studies
- ✓ Use declarative, story-telling headers
- ✓ Design for multiple reading pathways
- ✓ Match conclusion strength to evidence certainty
- ✓ Provide actionable recommendations

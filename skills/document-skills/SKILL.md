# Document Skills Adapter

This skill provides a **namespace adapter** for document creation capabilities powered by the [anthropic-agent-skills](https://github.com/anthropics/agent-skills) marketplace plugin.

> **Architecture Note**: This is a thin adapter with no processing logic. All document operations are handled by the installed marketplace plugin. This skill adds scientific workflow integrations and cross-references to other skills in this plugin.

## Available Sub-Skills

Use the `document-skills:` namespace prefix to invoke the marketplace capabilities:

| Namespace | Routes To | Purpose |
|-----------|-----------|---------|
| `document-skills:docx` | Marketplace docx skill | Word document creation/editing |
| `document-skills:pptx` | Marketplace pptx skill | PowerPoint presentation creation/editing |
| `document-skills:pdf` | Marketplace pdf skill | PDF manipulation (forms, extraction, merging) |
| `document-skills:xlsx` | Marketplace xlsx skill | Excel spreadsheet creation/editing |

## Usage

Reference these skills using the `document-skills:` namespace prefix:

```markdown
For PowerPoint output, use `document-skills:pptx`
For Word document export, use `document-skills:docx`
```

The adapter automatically routes to the installed marketplace plugin via `Skill(document-skills:format)`.

## Scientific Enhancements

When using any document-skills for scientific work, integrate these capabilities:

### Visual Enhancement with Scientific Schematics

**When creating documents, always consider adding scientific diagrams and schematics to enhance visual communication.**

If your document does not already contain schematics or diagrams:
- Use the **scientific-schematics** skill to generate AI-powered publication-quality diagrams
- Simply describe your desired diagram in natural language
- The AI will automatically generate, review, and refine the schematic

**For new documents:** Scientific schematics should be generated by default to visually represent key concepts, workflows, architectures, or relationships described in the text.

**How to generate schematics:**
```bash
python scripts/generate_schematic.py "your diagram description" -o figures/output.png
```

The AI will automatically:
- Create publication-quality images with proper formatting
- Review and refine through multiple iterations
- Ensure accessibility (colorblind-friendly, high contrast)
- Save outputs in the figures/ directory

### Format-Specific Schematic Use Cases

| Format | When to Add Schematics |
|--------|------------------------|
| PPTX | Workflow diagrams, slide design flowcharts, system architecture |
| DOCX | Document workflow diagrams, process flowcharts, organizational charts |
| PDF | Processing pipeline diagrams, data extraction visualizations |
| XLSX | Data processing pipelines, formula calculation flows, financial model structures |

For detailed guidance on creating schematics, refer to the **scientific-schematics** skill.

## Workflow Integration

### Scientific Writing Pipeline

```
scientific-writing → venue-templates → document-skills:docx
                                    └→ document-skills:pdf
```

### Presentation Pipeline

```
scientific-slides → document-skills:pptx
```

**Delegation contract:** `scientific-slides` owns narrative structure, citation sourcing, and figure planning. `document-skills:pptx` owns PPTX file generation (python-pptx), editing, and format conversion. Do not reimplement python-pptx work inside `scientific-slides`; do not reimplement slide-narrative logic inside `document-skills:pptx`. Trigger disambiguation lives in `skill-router/skill_triggers.yaml` via negative keywords ("conference talk" blocks the pptx route; "edit pptx" blocks the slides route).

### Branded Output Pipeline

```
oligon-brand → document-skills:docx (with docx_adapter)
            └→ markdown-to-pdf (for branded PDFs)
```

## Prerequisites

> **Required**: The `document-skills` marketplace plugin must be installed for document processing to work.
>
> Install from: [anthropic-agent-skills](https://github.com/anthropics/agent-skills)

Without the marketplace plugin installed, invocations of `document-skills:*` will fail.

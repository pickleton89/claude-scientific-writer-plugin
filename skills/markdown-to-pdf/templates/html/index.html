Report Templates · v1.0

Hand these to an LLM. Get an Oligon-styled report back.

Two reference templates and one authoring guide. Drop in markdown and figures; produce an HTML file in the house style, ready to print as PDF.

Variant 01 · Default

Editorial

Restrained, journal-feeling cover. Brand Blue used sparingly as accent. For pre-clinical, technical, and internal research reports.

 Variant 02 · Assertive

Banded

Brand Blue band on the cover with white wordmark. Same inner layout system. For executive briefings and external-facing reports.
For the LLM Read TEMPLATE_GUIDE.md first. It covers component vocabulary, voice rules, and the page-by-page mapping from markdown sections to layout slots. The HTML files are heavily commented — placeholder slots are written as {{LIKE_THIS}}.

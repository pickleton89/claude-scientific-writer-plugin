# Document Skills (Adapter)

This skill routes to the **anthropic-agent-skills** marketplace plugin for document format processing, with scientific workflow integrations.

## Important: Use Marketplace Skills

This project depends on the `document-skills` plugin from the anthropic-agent-skills marketplace. The actual document processing capabilities are provided by:

| Format | Marketplace Skill | Invoke With |
|--------|-------------------|-------------|
| Word (.docx) | `document-skills:docx` | `Skill(document-skills:docx)` |
| PDF (.pdf) | `document-skills:pdf` | `Skill(document-skills:pdf)` |
| PowerPoint (.pptx) | `document-skills:pptx` | `Skill(document-skills:pptx)` |
| Excel (.xlsx) | `document-skills:xlsx` | `Skill(document-skills:xlsx)` |

## Scientific Enhancements

When using any document-skills for scientific work, integrate these capabilities:

### Visual Enhancement with Scientific Schematics

**When creating documents, always consider adding scientific diagrams and schematics to enhance visual communication.**

If your document does not already contain schematics or diagrams:
- Use the **scientific-schematics** skill to generate AI-powered publication-quality diagrams
- Simply describe your desired diagram in natural language
- The AI will automatically generate, review, and refine the schematic

**For new documents:** Scientific schematics should be generated by default to visually represent key concepts, workflows, architectures, or relationships described in the text.

**How to generate schematics:**
```bash
python scripts/generate_schematic.py "your diagram description" -o figures/output.png
```

The AI will automatically:
- Create publication-quality images with proper formatting
- Review and refine through multiple iterations
- Ensure accessibility (colorblind-friendly, high contrast)
- Save outputs in the figures/ directory

### Format-Specific Schematic Use Cases

| Format | When to Add Schematics |
|--------|------------------------|
| PPTX | Workflow diagrams, slide design flowcharts, system architecture |
| DOCX | Document workflow diagrams, process flowcharts, organizational charts |
| PDF | Processing pipeline diagrams, data extraction visualizations |
| XLSX | Data processing pipelines, formula calculation flows, financial model structures |

For detailed guidance on creating schematics, refer to the **scientific-schematics** skill.

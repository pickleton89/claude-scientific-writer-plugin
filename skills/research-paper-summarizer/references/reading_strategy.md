# Strategic Reading for Scientific Summarization

## Overview

Effective summarization begins before writing—it starts with how you read. Scientific papers are designed for reference, not linear reading. Strategic reading extracts maximum insight with minimum time investment.

## The Non-Linear Reading Sequence

**Read sections in this order for optimal comprehension:**

```
1. Abstract     → Get the compressed narrative (2 min)
2. Conclusions  → Learn what was found (3 min)
3. Results      → See the evidence (5-10 min)
4. Introduction → Understand context and gap (3 min)
5. Methods      → Only if needed for interpretation (optional)
```

### Why This Order Works

| Order | Section | Purpose | Time |
|-------|---------|---------|------|
| 1st | **Abstract** | Rapid orientation—understand scope, approach, main finding | 2 min |
| 2nd | **Conclusions/Discussion** | Learn outcomes before process; know what to look for | 3 min |
| 3rd | **Results** | Evaluate evidence supporting conclusions; note key figures | 5-10 min |
| 4th | **Introduction** | Understand motivation, gap, and prior work context | 3 min |
| 5th | **Methods** | Reference only—consult for specific procedural questions | As needed |

**Total strategic read time:** 15-20 minutes vs. 45-60 minutes for linear reading

### The Methods Exception

Methods sections are essential for:
- Replication planning
- Methodological papers
- Evaluating study validity in peer review
- Computational/bioinformatics papers (methods ARE the contribution)

For general summarization, methods are the **least essential** section. Focus on what was found, not how every step was performed.

## Active Reading Techniques

### 1. Create a Running List of Main Points

As you read, maintain a mental or written list:

```
□ Main finding: [one sentence]
□ Key evidence: [2-3 data points]
□ Significance: [why it matters]
□ Limitations: [caveats to note]
```

### 2. Apply the Relevance Filter

For each piece of information, ask:

> "Does this support understanding the main finding?"

| Include | Discard |
|---------|---------|
| Findings that answer the research question | Routine procedural details |
| Statistical results with significance | Background already known to audience |
| Methods essential to understanding results | Tangential findings unrelated to thesis |
| Limitations affecting interpretation | Redundant restatements |

### 3. The "Weather Test"

From the best practice: "Mentioning it was 'raining' during an experiment is irrelevant, but mentioning a specific chemical reaction essential to the cure is vital."

**Ask:** If I removed this detail, would the summary lose meaning?
- **No** → Discard it
- **Yes** → Keep it

## Section-Specific Reading Goals

### Abstract
**Goal:** Extract the paper's "elevator pitch"

Look for:
- The problem/gap addressed
- The approach taken
- The main finding (often final 1-2 sentences)
- The significance claim

### Results/Conclusions
**Goal:** Understand what was discovered

Look for:
- Primary outcomes (usually stated first)
- Effect sizes and statistical significance
- Key figures and tables
- Authors' interpretation of findings

### Introduction
**Goal:** Understand the "why"

Look for:
- The knowledge gap (often in final paragraph)
- Key prior work cited
- The hypothesis or research question
- How this study fills the gap

### Methods
**Goal:** Reference for specific questions only

Consult when you need:
- Sample sizes and characteristics
- Specific procedures for replication
- Statistical approaches used
- Control conditions

## Reading for Different Summary Types

### For Paper Summaries (research-paper-summarizer)
- Emphasize Results and Conclusions
- Note all statistics with exact values
- Identify 2-3 key figures
- Capture critical analysis points

### For Executive Summaries
- Focus on significance and implications
- Translate technical findings to plain language
- Identify actionable recommendations
- Note the "so what?" for stakeholders

### For Abstracts
- Distill to single main message
- Include only essential methodology
- Lead with context, end with significance
- Stay within word limits (~150-300 words)

## Common Reading Mistakes

| Mistake | Problem | Fix |
|---------|---------|-----|
| Reading linearly start-to-finish | Wastes time; buries key findings | Use non-linear sequence |
| Over-reading Methods | Diminishing returns for summarization | Skim unless replicating |
| Taking notes on everything | Information overload | Apply relevance filter |
| Ignoring figures | Miss visual evidence | Review key figures explicitly |
| Skipping limitations | Miss critical caveats | Always note author-stated limits |

## Integration with Summarization Workflow

This reading strategy feeds directly into the summarization workflow:

1. **Strategic read** (this guide) → Build mental model
2. **Main idea extraction** → Draft topic sentence
3. **Evidence selection** → Choose supporting points
4. **Summary drafting** → Write in your own words
5. **Source comparison** → Verify accuracy
6. **Validation** → Check against summarization rules

# Peer Review Calibration Examples

> Anchor points for consistent scoring across review sessions.

## Purpose

These calibration examples provide reference points for the 8-dimension ScholarEval scoring framework. Each file contains:

- **Score 5** (Excellent): Exemplary quality, publishable in top venues
- **Score 4** (Good): Strong quality, minor improvements needed
- **Score 3** (Adequate): Acceptable, notable areas for improvement
- **Score 2** (Needs Work): Significant revisions required
- **Score 1** (Poor): Fundamental issues, major reconceptualization needed

## Available Calibration Files

| Dimension | Weight | File |
|-----------|--------|------|
| Methodology | 20% | `methodology_examples.md` |
| Analysis | 15% | `analysis_examples.md` |
| Results | 10% | `results_examples.md` |
| Writing | 10% | `writing_examples.md` |
| Literature Review | 15% | `literature_review_examples.md` |

## Usage

Before scoring a manuscript:

1. Review the relevant calibration examples for dimensions you're uncertain about
2. Compare your manuscript against the Score 3 example (threshold for acceptability)
3. Use the decision trees and key indicators to guide scoring
4. Document justification when scoring differs from calibration anchors

## Scoring Consistency Guidelines

### Cross-Session Consistency

To maintain consistency across review sessions:
- Always start by reviewing at least one calibration file
- Reference specific calibration examples in justifications
- Flag scores that deviate more than 1 point from initial impression

### Handling Edge Cases

When manuscripts don't fit calibration examples:
- Default to the lower score if between two levels
- Prioritize replicability for Methodology (20% weight)
- Prioritize clarity for Results and Writing
- Document the specific gap that prevented higher scoring

## Adding New Calibration Examples

When adding examples:
1. Use excerpts from real (anonymized) manuscripts when possible
2. Include both positive indicators (why this score) and negative (why not higher)
3. Provide a decision tree or rubric for ambiguous cases
4. Test with 3 independent reviewers for validation

# Document Types — Index

Document-type-specific structural and rhetorical guides. The IMRAD manuscript covered in `../imrad_structure.md` is the default; this directory holds specialized formats whose architecture differs materially from a standard research article.

| File | Document type | Status |

## When to consult

- During Stage 1 (outline) of the scientific-writing workflow, after determining the document type.
- During Plan Mode (§12 of `../../SKILL.md`) when the user is planning a document type covered here.
- For grant Specific Aims pages, the router should also pick up `grant specific aims`, `R01`, `NIH grant`, `aims page` triggers — see `skills/skill-router/skill_triggers.yaml`.

## Universal standards still apply

Every document in this directory inherits the universal voice/style standards in `../../../shared/references/prose_standards.md`. Type-specific guides extend or override those standards only where the document architecture demands it; they do not duplicate the universal rules.
